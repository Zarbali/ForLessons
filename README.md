**https://zarbali.github.io/ForLessons/**

### Если видишь 404 — сделай так (1 минута)

1. Открой: https://github.com/Zarbali/ForLessons/settings/pages  
2. **Build and deployment → Source** выбери: **Deploy from a branch**  
   (не GitHub Actions)  
3. **Branch:** `gh-pages`  
4. Folder: `/ (root)`  
5. Нажми **Save**  
6. Подожди 1 минуту и обнови сайт

Готовый сайт лежит в ветке `gh-pages` (уже залит).
