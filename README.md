# Veronika

Premium English learning web app — made with love.  
**No account required.** Progress is saved in the browser (Local Storage).

Сайт специально для моей любимой, удачи с учёбой)

## Features

- **1367+ words** across 12 categories (flashcards, vocabulary, games)
- **Learn:** Flashcards, Vocabulary, Grammar, Listening, Reading, Writing, Speaking
- **Games:** Memory, Match, Hangman, Word Builder, Speed, Sentence, Typing, and more
- **Smart AI tutor** (on-device)
- **Study music dock** — close anytime (X), reopen with Music button
- **Focus:** Pomodoro & study timer
- Dark / light mode, PWA, Framer Motion

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Framer Motion

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
